# llx_flutter_example

llx_flutter 插件的样例应用。

## 功能

- ✅ 加载 GGUF 模型文件
- ✅ 聊天界面（支持流式生成）
- ✅ LoRA 适配器管理
  - 添加 LoRA
  - 动态调整 scale（0.1 - 2.0）
  - 移除单个或所有 LoRA
- ✅ 基准测试
- ✅ Markdown 渲染
- ✅ 聊天历史管理

## 使用方法

### 1. 准备模型文件

下载一个 `.gguf` 格式的模型文件，例如：
- Qwen2.5-0.5B-Instruct-Q4_K_M.gguf
- Llama-3-8B-Instruct-Q4_K_M.gguf

### 2. 运行应用

```bash
cd flutter/llx_flutter/example
flutter run
```

### 3. 使用步骤

1. **加载模型**: 点击"加载 GGUF"按钮，选择模型文件
2. **发送消息**: 在输入框中输入消息，点击"发送"按钮
3. **添加 LoRA**（可选）: 点击"添加 LoRA"按钮，选择 LoRA 文件
4. **调整 scale**: 使用滑块调整 LoRA 的 scale 值
5. **运行测试**: 点击"Bench"按钮运行基准测试

## 界面说明

### 顶部状态栏
- 显示模型加载状态（已加载/未加载）
- 显示生成状态（生成中/空闲）

### 消息区域
- 用户消息（蓝色气泡，右对齐）
- AI 消息（灰色气泡，左对齐）
- 系统消息（浅灰色气泡，左对齐）
- LoRA 适配器列表（带滑块控制）

### 底部工具栏
- **输入框**: 输入消息内容
- **发送**: 发送消息并开始生成
- **清空**: 清空聊天历史
- **Bench**: 运行基准测试
- **加载 GGUF**: 选择并加载模型文件
- **添加 LoRA**: 选择并添加 LoRA 文件
- **清空 LoRA**: 移除所有 LoRA 适配器

## 注意事项

1. **首次使用**: 必须先加载模型才能发送消息
2. **模型大小**: 大模型（>2GB）可能需要较长加载时间
3. **内存占用**: 确保设备有足够内存（建议至少 4GB 可用内存）
4. **文件路径**: 模型文件会被复制到应用的外部存储目录
5. **生成速度**: 取决于模型大小和设备性能

## 故障排除

### 模型加载失败
- 检查文件格式是否为 `.gguf`
- 确保文件未损坏
- 检查设备可用内存

### 生成缓慢
- 尝试使用较小的模型
- 检查设备性能
- 减少上下文长度（nCtx）

### LoRA 加载失败
- 确保 LoRA 文件与模型兼容
- 检查文件格式是否正确
- 查看错误消息了解详情
